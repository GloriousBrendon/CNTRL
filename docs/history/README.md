# History

Working documents from before the first public release (0.7.0). They are kept as a record of how
CNTRL got here; none of them describes the current code. For that, read the top-level `README.md`
and `docs/design/HANDOFF.md`.

| Folder | What it was |
|---|---|
| `plan-2026-10/` | The plan and task list for the fan-control and RGB work (closed 2026-10-12). Boxes left unticked there were manual checks; the owner confirmed the panel, reboot, suspend and keyboard-replug behaviour by hand before release rather than ticking them one by one. |
| `reviews/` | The code review that started that work. |
| `milestone/`, `baseline/` | The GTK → iced migration (see `docs/adr/0001`). The GTK app no longer exists. |
| `PHASE1_LIGHTING.md` | Notes from the earlier Tauri prototype. |
